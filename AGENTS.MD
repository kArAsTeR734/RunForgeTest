# Инструкции для агента

Перед анализом, разработкой или изменением файлов этого проекта обязательно прочитай:

1. [agents/AGENTS.MD](agents/AGENTS.MD) — правила разработки, распространяющиеся на весь проект.
2. [agents/REQUIREMENTS.MD](agents/REQUIREMENTS.MD) — требования из PDF, приоритеты и критерии приёмки.
3. [README.MD](README.MD) — запуск, структура и фактическое состояние реализации.

Корневой файл служит переходом к инструкциям в `/agents`; не дублируй здесь подробные правила.
Файл в `/agents` нужно читать явно: его расположение само по себе не распространяет инструкции на `src`.
