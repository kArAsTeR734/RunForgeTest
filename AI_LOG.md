## Текущий этап: основа проекта и документация

Инструмент: Codex desktop, ассистент на базе GPT-6. Точный идентификатор выбранной модели не предоставлен в контексте сессии; при необходимости владелец уточняет его по интерфейсу.

Переданный контекст: PDF тестового Runforge, существующие пустые папки проекта и запрос пользователя подготовить README, инструкции AGENTS, требования и основу на выбранном стеке.

Фактический запрос пользователя, сокращённо: «Проанализировать PDF; написать README.MD, AGENTS.MD с переходом в /agents; придерживаться структуры; создать проект на указанном стеке с CSS Modules и mock-сервисом; вынести требования в /agents/REQUIREMENTS.MD».

Результат: React + Vite + TypeScript, асинхронный mock-сервис с задержкой, ошибкой и отменой, шесть запусков, базовый список, тесты сервиса и документация. Поиск, фильтры и подробности ещё не реализованы.

## Основные сценарии Runs

Третий полезный запрос пользователя: вынести фильтры перед списком отдельным компонентом, разбить App и реализовать фильтрацию, поиск и подробности в модальном окне до перехода к бонусам.

App теперь только собирает AppHeader и RunsPage. Сценарии разделены на RunsHeader, RunFilters, RunsContent, RunList и RunDetailsModal. Поиск по названию/репозиторию работает вместе со статусом; пустой результат позволяет сбросить оба условия. В подробностях есть поля выбранного запуска, логи и необязательный результат. Нативный dialog закрывается кнопкой или Escape, блокирует фон, после закрытия восстанавливает фокус. Выбранные поиск и статус сохраняются.

Сохранён вариант useRuns с async/await, внесённый пользователем. Для вызова из эффекта добавлено точечное пояснение-исключение правила set-state-in-effect: внутри fetchRuns состояние меняется только после await, синхронного обновления из эффекта нет.

Добавлены 11 тестов страницы. При проверке TypeScript обнаружен неверный параметр `exact` в запросах Testing Library getByRole; параметр удалён, строковый name уже задаёт точное сопоставление.

Браузерная проверка: список и диалог просмотрены на desktop и при viewport 360 × 800. Проверены совместные Running + api-service, пустой результат и сброс, управляемая ошибка и повтор, результат успешного запуска, Escape, возврат фокуса и удержание фокуса в модальном окне. На 360 px ширина документа равна 360 px, горизонтального переполнения нет. Error/warn в консоли не обнаружены. Проверка выполнена в одном браузере, не является проверкой всех браузеров.

Сортировка, URL-фильтры, публикация демо и отправка проекта не выполнялись. Финальные проверки прошли: `npm run lint`, `npm run format:check`, `npm test` (19 тестов в трёх файлах) и `npm run build` с проверкой TypeScript.
